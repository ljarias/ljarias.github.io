Cómo leer los indicadores

Avance documental del PR y la rama: expresa casillas marcadas sobre casillas totales. No mide automáticamente porcentaje de código, tiempo invertido ni calidad de pruebas.

Cierre de fase: cuando existe un archivo de criterios, solo cuenta requisitos con estado verificado/accepted/closed. implemented o qa se muestran aparte y no equivalen a cierre.

Pruebas CI: el estado se asocia con el SHA actual de la rama o PR. Una ejecución verde no demuestra por sí sola que una fase sea apta para producción.

Conexión: reintenta cada 50 segundos y al regresar internet o reabrir la pestaña. Las actualizaciones no continúan mientras el navegador está cerrado; nunca se ejecutan tareas de desarrollo desde este tablero.
