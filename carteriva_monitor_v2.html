Cómo leer los indicadores

Indicadores de fase: implementación = requisitos en implementación terminada, QA o verificados / total; cierre = únicamente criterios aceptados y verificados / total. No confundirlos con despliegue.

Ruta crítica: cadena más larga de PR abiertos relacionados por ramas base. Es una heurística de dependencias, no una estimación temporal.

Avance documental del PR y la rama: expresa casillas marcadas sobre casillas totales. No mide automáticamente porcentaje de código, tiempo invertido ni calidad de pruebas.

Cierre de fase: cuando existe un archivo de criterios, solo cuenta requisitos con estado verificado/accepted/closed. implemented o qa se muestran aparte y no equivalen a cierre.

Pruebas CI: el estado se asocia con el SHA actual de la rama o PR. Una ejecución verde no demuestra por sí sola que una fase sea apta para producción.

Historial: compara únicamente muestras tomadas por este monitor; no infiere trabajo entre dos fechas de captura. Guardar métricas de forma persistente es opcional.

Seguridad: el token es de solo lectura y se mantiene en memoria por defecto. La sesión recordada es opcional y puede ser leída por otros scripts de este mismo origen público; para una mayor separación se requeriría alojar el monitor en un origen independiente con un servicio de autenticación dedicado.

Conexión: reintenta cada 50 segundos y al regresar internet o reabrir la pestaña. Las actualizaciones no continúan mientras el navegador está cerrado; nunca se ejecutan tareas de desarrollo desde este tablero.
