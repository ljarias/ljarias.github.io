1. Elige cómo conversará tu chatbot

💬 Preguntas frecuentes (FAQ)

El usuario escribe una consulta. El chatbot busca palabras o frases reconocidas y muestra una respuesta preparada.

Ejemplo: Escribes «¿A qué hora abre la biblioteca?» → identifica «horario» y responde.

Útil cuando las personas formulan preguntas similares de diferentes maneras. No utiliza un árbol de opciones.

Crear chatbot de preguntas frecuentes

🌳 Árbol de decisiones

El usuario elige opciones visibles. Cada respuesta lleva a otra pregunta o a una solución final.

Ejemplo: «¿El computador enciende?» → «Sí» o «No» → sigue una ruta de diagnóstico distinta.

Útil para diagnósticos guiados, trámites, orientación y clasificación de problemas.

3. ¿Y si ya tienes un proyecto guardado?

En cada editor encontrarás «Abrir mi proyecto JSON» para recuperar un archivo que guardaste anteriormente. Para practicar con los ocho ejemplos no necesitas utilizar ese botón: también están disponibles en la opción «Cargar ejemplo» dentro de cada editor.

Offline: los ejemplos y el funcionamiento del chatbot no requieren internet. Los enlaces externos, como WhatsApp, sí lo necesitan.
