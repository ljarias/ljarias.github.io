Nombre y descripción

1. Diseña las rutas finales

Una ruta final es la recomendación que verá la persona cuando termine el árbol. Si necesita contactar a un responsable, escribe su número de WhatsApp de Colombia con indicativo 57, sin + ni espacios (ejemplo ficticio: 573001234567).

2. Construye las preguntas

Cada pregunta puede tener 1, 2, 3, 4… o N respuestas. Cada opción representa una condición («SI elige esta respuesta, ENTONCES…») y DEBE llevar a otra pregunta o a una ruta final. Puedes añadir y quitar respuestas.

Ejemplo: «¿Qué necesitas?» puede tener 3 respuestas: «Ver productos», «Preguntar por entregas» y «Hablar con alguien». Cada opción puede llevar a una pregunta o a una solución diferente. Las opciones nuevas quedan pendientes hasta que las conectes.

3. Revisa tu árbol

Este esquema permite revisar los caminos. El verificador comprueba que TODAS las respuestas tengan destino válido, alcancen una solución final y no existan ciclos ni rutas desconectadas.

4. Prueba como si fueras el usuario

El chatbot se ejecuta dentro de esta ventana. Sus preguntas funcionan offline.

5. Guarda y comparte

El JSON sirve para volver a editar. El HTML es el chatbot completo para abrir en el navegador del computador o celular.

En el celular: envía el HTML al teléfono y ábrelo en un navegador o visor HTML que permita JavaScript. Algunos celulares bloquean archivos locales: en ese caso, publícalo en una página web HTTPS sencilla y comparte el enlace. Para usar WhatsApp hace falta conexión.

Empieza con el proyecto genérico, modifica una pregunta y prueba el árbol. Para practicar usa «Cargar un ejemplo» al principio del editor.
