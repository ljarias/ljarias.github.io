Tablero de Monitoreo de una Red Piezométrica Departamental

Dashboard web estático para consultar y analizar lecturas de una red de monitoreo de aguas subterráneas en el Cesar.

Estado: Aplicativo HTML identificado; despliegue público por comprobar

¿Qué permite explorar?

  • Explorador geográfico de piezómetros
  • Filtros por estación, cuenca y fechas
  • Series temporales, comparaciones e indicadores de calidad
